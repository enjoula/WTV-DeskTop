# WTV Desktop 技术架构文档

## 📐 架构概览

WTV Desktop 采用 **Electron + React** 的跨平台桌面应用架构，遵循 Electron 的标准双进程模型。

```
┌─────────────────────────────────────────────────────────┐
│                    Electron 应用层                        │
├─────────────────────────────────────────────────────────┤
│  主进程 (Main Process)          │  渲染进程 (Renderer Process) │
│  ┌──────────────────────┐      │  ┌──────────────────────┐   │
│  │  main.js             │      │  │  React 应用          │   │
│  │  - 窗口管理           │◄─────┤  │  - UI 组件            │   │
│  │  - IPC 通信           │ IPC  │  │  - 状态管理          │   │
│  │  - 系统集成           │      │  │  - 路由管理          │   │
│  └──────────────────────┘      │  └──────────────────────┘   │
│           │                     │           │                 │
│           │                     │           │                 │
│  ┌──────────────────────┐      │  ┌──────────────────────┐   │
│  │  preload.js          │      │  │  API 客户端          │   │
│  │  - 安全桥接           │      │  │  - Axios             │   │
│  │  - Context Bridge     │      │  │  - 请求拦截          │   │
│  └──────────────────────┘      │  └──────────────────────┘   │
└─────────────────────────────────────────────────────────┘
           │                               │
           └───────────┬───────────────────┘
                       │
              ┌────────▼────────┐
              │   后端 API 服务器  │
              │  http://124.222.  │
              │  196.128:6660     │
              └──────────────────┘
```

## 🔄 数据流架构

### 1. 用户交互流程

```
用户操作
   │
   ▼
React 组件 (UI)
   │
   ▼
Redux Action (dispatch)
   │
   ▼
Redux Thunk (异步处理)
   │
   ▼
API 客户端 (Axios)
   │
   ▼
后端 API 服务器
   │
   ▼
响应数据
   │
   ▼
Redux Reducer (更新状态)
   │
   ▼
React 组件 (重新渲染)
```

### 2. IPC 通信流程

```
渲染进程 (Renderer)
   │
   ▼
window.electronAPI (Context Bridge)
   │
   ▼
preload.js (安全桥接)
   │
   ▼
IPC Renderer (ipcRenderer.invoke)
   │
   ▼
主进程 (Main Process)
   │
   ▼
IPC Main (ipcMain.handle)
   │
   ▼
系统 API / 文件操作
```

### 3. 状态管理架构

```
┌─────────────────────────────────────┐
│         Redux Store                  │
├─────────────────────────────────────┤
│  authSlice                           │
│  ├── isAuthenticated                 │
│  ├── user                            │
│  └── token                           │
├─────────────────────────────────────┤
│  videoSlice                          │
│  ├── movies/tvShows/anime/...        │
│  ├── playUrl                         │
│  ├── playbackProgress               │
│  └── currentCategory                │
├─────────────────────────────────────┤
│  favoriteSlice                       │
│  └── favorites                       │
└─────────────────────────────────────┘
```

## 🎯 核心功能模块

### 1. 认证模块

- **登录/注册**: 用户名密码认证
- **Token 管理**: JWT Token 存储与刷新
- **401 处理**: 自动跳转登录页
- **设备识别**: 平台标识 (Mac-Intel/Mac-ARM/Windows)

### 2. 视频模块

- **视频列表**: 分页加载、无限滚动
- **视频详情**: 详情信息、剧集列表
- **视频播放**: HLS 流播放、进度保存
- **搜索筛选**: 关键词搜索、多条件筛选
- **收藏管理**: 收藏/取消收藏

### 3. 更新模块

- **更新检查**: 每日首次启动检查
- **强制更新**: 阻止使用直到更新
- **非强制更新**: 用户选择是否更新
- **平台识别**: 区分 Mac-Intel/Mac-ARM/Windows

### 4. 播放记录模块

- **本地存储**: localStorage 持久化
- **进度保存**: 自动保存播放进度
- **续播功能**: 从上次位置继续播放

## 🔐 安全机制

### 1. Context Isolation

- 使用 `contextBridge` 安全暴露 API
- 防止渲染进程直接访问 Node.js API

### 2. CORS 处理

- 主进程配置 CORS 头
- 支持跨域图片和视频流加载

### 3. Token 管理

- Token 存储在 localStorage
- 请求自动携带 Token
- 401 自动清除 Token 并跳转

## 🔄 更新机制

### 更新检查流程

```
应用启动
   │
   ▼
检查今日是否已检查 (localStorage)
   │
   ▼
调用更新检查 API
   │
   ├── 有更新
   │   ├── 强制更新 → 显示更新对话框 (不可关闭)
   │   └── 非强制更新 → 显示更新对话框 (可关闭)
   │
   └── 无更新 → 继续使用
```

## 📝 开发规范

### 代码组织

- 组件按功能分类
- API 按业务模块分类
- 工具函数独立文件

- 组件: PascalCase (如 `VideoDetail.js`)
- 函数: camelCase (如 `handlePlay`)

- 使用 Redux Toolkit
- 异步操作使用 `createAsyncThunk`
- 状态切片按功能划分
